#### Принцип обучения Розенблатта:
* Персептрон обучается в дискретном времени на обучающей выборке пар $(x^{(k)}, d^{(k)})$, где $d^{(k)} \in \{-1, +1\}$.
* Если сеть выдает правильный ответ ($y = d$), синаптические веса остаются без изменений.
* В случае ошибочной классификации веса корректируются по аддитивному правилу:
$$w_i(t+1) = w_i(t) + \eta \cdot d^{(k)} \cdot a_i^{(k)}$$
где $a_i^{(k)} \in \{0, 1\}$ — состояние выхода $i$-го ассоциативного нейрона, $\eta$ — параметр шага обучения. Теорема Розенблатта о сходимости гарантирует, что если классы линейно разделимы, алгоритм сойдется за конечное число шагов.

### Задание 2. Алгоритм обратного распространения ошибки (Backpropagation)

| Этап алгоритма | Описание шага и расчетные соотношения |
|---|---|
| **Шаг 1. Инициализация параметров сети** | Все весовые матрицы $W^{(l)}$ инициализируются малыми псевдослучайными числами (схема He/Xavier), вектор смещений $b^{(l)} = 0$. Устанавливаются гиперпараметры: learning rate $\eta$, batch size. |
| **Шаг 2. Прямое распространение (Forward Pass)** | Вектор признаков логистической накладной $x$ подается на входной слой и послойно распространяется к выходу:<br>$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}, \quad a^{(l)} = \sigma\left(z^{(l)}\right)$$<br>Значения активаций всех промежуточных слоев сохраняются в оперативной памяти. |
| **Шаг 3. Расчет значения функции потерь** | На выходном слое $L$ вычисляется расхождение между прогнозом $\hat{y} = a^{(L)}$ и реальным значением целевого показателя $y$ (например, MSE):<br>$$L = \frac{1}{2} \sum_{k} (y_k - \hat{y}_k)^2$$ |
| **Шаг 4. Вычисление градиента ошибки выходного слоя** | По правилу дифференцирования сложной функции вычисляется вектор локальной ошибки:<br>$$\delta^{(L)} = \frac{\partial L}{\partial z^{(L)}} = (\hat{y} - y) \odot \sigma'\left(z^{(L)}\right)$$ |
| **Шаг 5. Обратный проход ошибки (Backward Pass)** | Ошибка рекурсивно пробрасывается назад от слоя к слою:<br>$$\delta^{(l)} = \left( (W^{(l+1)})^T \delta^{(l+1)} \right) \odot \sigma'\left(z^{(l)}\right)$$ |
| **Шаг 6. Расчет градиентов по весам и смещениям** | Вычисляются частные производные функционала потерь:<br>$$\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} (a^{(l-1)})^T, \quad \frac{\partial L}{\partial b^{(l)}} = \delta^{(l)}$$ |
| **Шаг 7. Обновление синаптических весов (Градиентный спуск)** | Коррекция весов выполняется в направлении антиградиента:<br>$$W^{(l)} \leftarrow W^{(l)} - \eta \frac{\partial L}{\partial W^{(l)}}, \quad b^{(l)} \leftarrow b^{(l)} - \eta \frac{\partial L}{\partial b^{(l)}}$$ |
| **Шаг 8. Оценка сходимости и критерий останова** | Если среднеквадратичная ошибка на валидационном наборе данных перестала убывать в течение $N$ эпох (Early Stopping), процедура обучения завершается. |

### Задание 4. Сравнение релаксационных нейронных сетей

| Сеть | Принцип действия и архитектурные особенности | Достоинства | Недостатки |
|---|---|---|---|
| **Сеть Хопфилда (Hopfield Network)** | Однослойная полносвязная рекуррентная сеть с симметричными связями ($w_{ij} = w_{ji}$) и нулевой автосвязью ($w_{ii}=0$). Обладает функцией энергии Ляпунова, минимизируемой при переходах состояний. Работает как ассоциативная память. | • Высокая скорость релаксации (схождения к эталонному образу).<br>• Обучение за один шаг по формуле Хебба без итераций.<br>• Гарантированная устойчивость динамической системы. | • Ограниченная емкость памяти: $M_{\max} \approx 0.14 \cdot N$ эталонов.<br>• Появление паразитных ложных аттракторов (ложных воспоминаний) при переполнении сети. |
| **Сеть Хемминга (Hamming Network)** | Двухслойная сеть: 1-й слой рассчитывает метрику схожести входного вектора со всеми сохраненными эталонами (расстояние Хемминга), а 2-й слой (Maxnet) с взаимным латеральным торможением выделяет максимальный узел. | • Емкость памяти не ограничена числом входов (отсутствуют паразитные состояния Хопфилда).<br>• Требует меньше физических синаптических связей.<br>• Идеальна для распознавания бинарных шаблонов. | • Работает только с бинарными/биполярными векторами строго фиксированной размерности.<br>• Низкая эффективность на непрерывных аналоговых сигналах. |
| **Машина Больцмана (Boltzmann Machine)** | Стохастическая релаксационная сеть со скрытыми и видимыми нейронами. Вероятность перехода определяется распределением Гиббса-Больцмана. Использует имитацию термического отжига для избежания локальных минимумов энергии. | • Способна находить глобальный минимум функции энергии благодаря стохастическому преодолению потенциальных барьеров.<br>• Способна строить вероятностные генеративные модели данных. | • Экстремально высокая вычислительная ресурсоемкость и колоссальное время обучения методом сэмплирования Гиббса. |
